# 🎮 Word Guessing & Math-Based Game

A Python-based game project that combines word guessing challenges with mathematical problem-solving.

The project brings together two different types of gameplay, offering an interactive experience that encourages logical thinking, problem-solving, and analytical skills.

## ✨ Features

### 🔤 Word Guessing Game
- Word guessing challenges
- Interactive gameplay
- Letter-based guessing mechanics
- Vocabulary development
- Logical thinking and deduction

### 🔢 Math-Based Game
- Mathematical challenges
- Problem-solving exercises
- Number-based gameplay
- Analytical thinking
- Mathematical reasoning

### 🎯 Learning Through Gaming
- Combines entertainment with learning
- Encourages critical thinking
- Improves problem-solving skills
- Provides an interactive gaming experience

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/betulkulaksizz/Kelime-Tahmin-Ve-Matematik-Tabanl-Oyun.git
```

### 2. Navigate to the Project Directory

```bash
cd Kelime-Tahmin-Ve-Matematik-Tabanl-Oyun
```

### 3. Install Dependencies

If a `requirements.txt` file exists:

```bash
pip install -r requirements.txt
```

### 4. Run the Application

Run the project's main Python file:

```bash
python main.py
```

Replace `main.py` with the actual entry-point filename if necessary.
